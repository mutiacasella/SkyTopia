# SkyTopia – Integrated Daycare Center Management System

SkyTopia is a comprehensive web-based daycare management system designed to support multi-branch operations through a centralized platform. The system aims to streamline administrative processes, improve communication among stakeholders, and provide structured access to data for administrators, teachers, and parents.

## 🎯 Project Overview

SkyTopia is designed to address common challenges in daycare management such as fragmented data, manual administrative processes, and limited communication between stakeholders.

The system integrates multiple operational modules into a single platform, enabling efficient management of:

- Child records and profiles  
- Teacher schedules and assignments  
- Financial transactions and payment tracking  
- Reporting and performance summaries  
- Multi-branch coordination  

Additionally, the system supports improved accessibility for parents, allowing them to monitor their child’s progress, review reports, and track payments.

---

## 🚀 Key Features

- Multi-role access control (Admin, Teacher, Parent)
- Child data management (CRUD operations)
- Financial tracking and invoice management
- Reporting and dashboard system
- Role-based data isolation and permissions
- Multi-branch ready architecture
- Centralized database for structured data management

---

## 🧩 Modules

- **Child Management Module**  
  Handles storage and management of child-related data including personal information, health records, and emergency contacts.

- **Financial Management Module**  
  Manages payment tracking, transaction history, and invoice generation with visibility for both administrators and parents.

- **Reporting and Dashboard Module**  
  Provides summarized insights such as total students, teachers, and payment statuses, along with user-specific reports.

- **User Management and Access Control Module**  
  Implements role-based access control to ensure secure and restricted data access across different user roles.

- **AI-Powered Chatbot Module**  
  Provides automated assistance for handling user queries and improving interaction efficiency.

## 🧱 Architecture Overview

- RESTful API-based backend architecture  
- Modular system design for scalability  
- Role-based access control (RBAC)  
- Centralized database with structured collections  
- Separation of concerns between frontend and backend  
- Cloud-based deployment for accessibility and scalability
